# ADR-006 — 离线日语 ASR 引擎与模型分发

Status: Accepted
Date: 2026-09-05

## Context

`01_PRD §31` 与 `Task OfflineJapaneseASR` 要求完全离线的日语语音识别，但没有任何文档说明**模型如何到达设备**。这决定构建形态（APK / AAB / asset pack）、APK 体积基线、以及产品「无需互联网」承诺的边界，必须在工程初始化之前定下。

## Decision

### 1. 引擎

首选 **Vosk**（`vosk-android`），日语小模型（`vosk-model-small-ja`，量级约 40–50 MB 解压后）。

选型必须在 `Task OfflineJapaneseASR` 开始前复核：

- 当前版本是否提供 **16 KB page size 对齐**的 `.so`（Android 15+ 要求）；不满足则需用较新 NDK 自行编译或更换引擎。
- ABI 覆盖 `arm64-v8a` 与 `armeabi-v7a`。
- 许可证与再分发条款（引擎与模型可能不同）。
- 在 MTK P22 / 4 GB 设备上的常驻内存与识别耗时。

如复核不通过，另立 ADR 记录更换结论，不得静默替换。

### 2. 模型分发：首次启用时下载

- 模型**不打进 APK**。
- ASR 默认关闭。用户在设置中首次开启时，显示明确提示：「初回のみ約 50 MB のダウンロードが必要です」，用户确认后下载。
- 下载完成后写入应用私有目录，**此后永久离线可用**；重装应用需重新下载。
- 下载失败 / 中断：ASR 保持关闭状态，PTT 与历史记录完全不受影响。
- 模型文件校验：记录预期大小与摘要，校验失败则删除并要求重新下载。

### 3. 产品承诺的边界（必须写入 PRD 与 README）

> 核心功能——设备发现、在线状态、一对一 PTT、录音、回放、历史记录——**永不需要互联网**。
> 唯一的例外是：**离线日语字幕功能首次启用时，需要一次联网下载识别模型**。下载完成后，识别过程本身 100% 本地，不上传任何音频或文本。

### 4. 被否决的方案

| 方案 | 否决理由 |
|---|---|
| 内置进 APK | APK 体积增加 40–50 MB；ASR 默认关闭，绝大多数用户为不使用的功能付出下载与存储成本；与「轻量」定位冲突 |
| Play Asset Delivery | 强制走 AAB + Play 渠道，侧载与企业内部分发场景失效；本产品面向仓库/工厂等常见内部分发场景 |

## Consequences

- `Task AndroidProjectInitialization` / `Task BuildAndDependencyBaseline` 不需要为模型预留打包配置，但需要预留 NDK/ABI 配置（Vosk 与 Opus 都是原生库）。
- 需要一条受控的下载路径（仅此一处使用网络，仅用于下载模型），必须在隐私说明中单独列出。
- `01_PRD §31`、`00_MasterPrompt §5/§21`、`README` 的「完全离线」措辞需加入此例外。
- ASR 任务在开发顺序中下沉至历史记录功能之后（它是可选功能，优先级低于核心通信与历史）。
